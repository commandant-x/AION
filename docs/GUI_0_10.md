# AION CORE 0.10 — Windows Native Visualizer

This is a **graphical** Win32 executable backed directly by `aion-rust-sim`, not by the legacy C reference engine.

## Controls

- Mouse drag: orbit 3D-projected view
- Mouse wheel: zoom
- I: impact / T: traction / H: heat / Space: pause
- R: reset / S: save AION7 / L: restore AION7
- 1 / 2 / 3: material preset

Use the buttons on the right of the window or the corresponding keyboard shortcuts.

## Verification

GitHub Actions (Windows runner) runs `aion-window.exe --self-test` and `--window-smoke` before uploading the GUI `.exe`. The window smoke test creates a real Win32 window, constructs a GDI device context and draws the current Rust simulation into a compatible bitmap. This does **not** prove display output on every user's GPU or screen; it verifies window initialization on Windows CI.

## Technical scope

The 3D scene uses perspective-style **software projection** onto Win32 GDI. It is a genuine native graphical window (not HTML), but it is **not** yet the planned WebGPU/wgpu renderer. The main goal of this version is to correct the previous CLI-only delivery while connecting the visualizer to the real Rust solver.

The saved `aion_checkpoint.aion7` file is written next to the executable. Run from a writable directory. The current format is AION7.
